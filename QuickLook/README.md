# Quick Look TOP

任意ファイル(PDF/動画/3D/書類/画像/フォント等)を **QuickLookThumbnailing** で **OS標準のサムネイル画像**に
して BGRA8 TOP として出力する。Finder のプレビューと同じ仕組み。cook はブロックせずワーカーで生成。

## 実測(M2)

- テストPDF → 198x256 のサムネイルを生成(縦横比を保持)

## パラメータ

| パラメータ | 説明 |
|---|---|
| File | 任意のファイル |
| Width / Height | 要求サイズ(実出力は縦横比維持で変わる) |
| Icon Mode | アイコン(バッジ/枠付き)表現にする |

## 注意
- 実出力サイズはファイルの縦横比で決まる(要求サイズは上限の目安)
- 生成不可のファイルは Warning。TOPは bottom-up なので内部で上下反転して描画済み

## ビルド
```
cd QuickLook && ./build.sh
```
